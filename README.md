# ibressan.github.io

Código-fonte do meu site pessoal (https://ibressan.github.io), gerado a partir do
[GitProfile](https://github.com/arifszn/gitprofile), com personalizações de tema
e uma seção extra que traz as edições do [Salesforce News](https://github.com/ibressan/salesforce-news).

Configuração em [`gitprofile.config.ts`](gitprofile.config.ts). O deploy é
automático via GitHub Actions a cada push na branch `main`.
